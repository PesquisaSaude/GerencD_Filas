Operação
Limitação do protótipo: os dados provêm do armazenamento local deste navegador e não formam uma base centralizada entre estações. Para indicadores corporativos consolidados, é necessária integração com uma API e banco de dados compartilhado. Métricas de primeira chamada usam os registros de histórico disponíveis e podem ser incompletas em backups antigos.
